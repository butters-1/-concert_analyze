# -concert_analyze

## Documentation Structure

This repository follows the [Diátaxis](https://diataxis.fr/) framework curated by the Docs Curator agent (`.agents/docs-curator.md`):

- **`docs/how-to/`**: Practical guides for completing specific tasks.
- **`docs/adr/`**: Architecture Decision Records capturing design choices and technical tradeoffs.
- **`docs/skills/`**: Standard operating procedures and repeatable technical workflows.
- **`docs/reference/`**: Ground truth specifications, configuration schemas, and domain constraints (e.g., `business-rules.csv`).
- **`docs/explanation/data-concepts/`**: Conceptual explanations of data models, domains, and business contexts.
- **`docs/tutorials/`**: Step-by-step onboarding and learning guides.
