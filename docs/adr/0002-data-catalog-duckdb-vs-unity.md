# Data Catalog: DuckDB vs. Unity Catalog

## Title
Data Catalog: DuckDB vs. Unity Catalog

## Status
Proposed

## Context
We need to decide on the database for our data catalog. We have two options: DuckDB and Unity Catalog.

## Decision
We will use DuckDB for our data catalog.

## Consequences
This will allow us to have a lightweight, file-based querying system that is easy to set up and use.
